# 中南大学住宿打卡

单账号插件，使用 Windows 上的 Microsoft Edge 和学校官方 [智慧学工页面](https://zhxg.csu.edu.cn/znzhxgpt_h5/#/ywViews/qxjlfx/dk/index)。适用于本人在打卡地点、浏览器能读取该设备真实位置的场景。电脑定位失败时，请在手机上打开官方页面办理。

安装 Edge 后，通过 AstrBot 插件管理安装。管理员私聊发送 /住宿打卡 扫码，阅读学校协议后发送 /住宿打卡 扫码 同意。保存收到的登录码，在微信扫一扫中从相册选择并确认。也可用 /住宿打卡 登录，在运行机器的 Edge 完成学校认证。

/住宿打卡 检查 只校验登录和真实定位。/住宿打卡 打卡 手动提交一次。/住宿打卡 开启 20:10 设置每天北京时间 20:10，允许设置 20:00–23:29。/住宿打卡 状态 查看结果，/住宿打卡 关闭 停止定时。进程须在设定分钟在线。离开打卡地点前请停用定时。

只安装给一个账号使用。学校会话保存在本机插件数据目录的 edge 子目录，对话中无需发送学号密码或 Cookie。过期后重新扫码。删除浏览器资料前先关闭插件或等待当前任务结束。
